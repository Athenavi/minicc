## 前端修复：admin 视图模板 JSX/React 语法（commit d795490）

- **报错**：DomainManagement/RedisManagement/DatabaseManagement 三个视图 `:columns="[` 处编译失败
- **根因**：5 个 admin 视图（含 TenantManagement/AdminDashboard）在 Vue 模板属性里内联 JSX——`customRender: () => (<Tag>...)`，外加大量 React 式 props（`footer={null}` `onOk={fn}` `v-model:value={x}` `style={{}}`）。因 vite 按需编译、这些页面从未被访问，错误一直潜伏
